# General Utils

## Poppler Utils

Executables provided by the mise `poppler` package (`conda` backend), a set
of CLI tools using [Poppler](https://poppler.freedesktop.org/):

- `pdfattach`
- `pdfdetach`
- `pdffonts`
- `pdfimages`
- `pdfseparate`
- `pdfsig`
- `pdftocairo`
- `pdftohtml`
- `pdftoppm`
- `pdftops`
- `pdftotext`
- `pdfunite`
